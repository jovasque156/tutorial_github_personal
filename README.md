# 📚 Recetario colaborativo

Este proyecto es un ejemplo simple para aprender a usar Git.

La idea es que cada persona:
- Agregue nuevas recetas
- Modifique recetas existentes
- Practique commits, ramas y merges

## 🧑‍🍳 Reglas
- Cada receta debe estar en su propio archivo
- Usar nombres claros
- Escribir ingredientes y pasos
